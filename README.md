# KubaLabs

Osobní hub her, aplikací, webových projektů a praktických nástrojů Jakuba Michálka.

## Obsah

- `index.html` — hlavní projektový hub
- `hry.html` — hry a strategické simulátory
- `nastroje.html` — přehled praktických nástrojů
- `rozpis.html` — generátor turnajového rozpisu
- `styles.css` — společný responzivní design systém
- `app.js` — navigace, animace, filtrování a vyhledávání

Web je postavený bez frameworku a externích závislostí pro rychlé načítání na GitHub Pages.
